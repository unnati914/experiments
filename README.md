# experiments

Side projects and prototypes, one folder each.

| Folder | What it is |
| --- | --- |
| [hiring-video](hiring-video) | Remotion code for my pitch videos and the *AI Failure Files* series, plus the Python scripts for music, voice cleanup, cutting and speed-up |
| [poc-kit](poc-kit) | An eval proof-of-concept kit: test suites run against 100+ companies, plus the demo sites built from the results |
| [freh-poc](freh-poc) | Freh proof of concept (static site) |
| [syaat-revamp](syaat-revamp) | A redesign of the Syaat website |
| [repowise-demo](repowise-demo) | "First day on Flask": an onboarding walkthrough generated for the Flask codebase |

Not included: rendered videos, voice recordings, music, photos and other media, model weights, `node_modules`, logs and any `.env` files. The video projects need those assets to render.
