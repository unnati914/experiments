Agent Watch: pay for progress, not for loops.

A small guard that watches an AI build agent while it works. It stops loops, catches fixes that break older features, checks every "Done!" against the real app, and doesn't charge credits for wasted steps.

    Loop stop

    Same error 3 times → pause and ask the user, don't keep charging.

    Regression guard

    Every fix re-runs the tests that already passed. Broken → roll back.

    "Done" check

    Each feature the agent says it built must exist in the code and pass a test.

    Fair credits

    Steps that fix the agent's own mistakes are free.
    🔁

    Credits burn in loops

    Reviewers say debugging eats credits even when the AI caused the bug. One saw a dark-mode toggle take 12 credits to fix.

    💔

    Fixes break old features

    A fix for one bug quietly breaks something that worked before, and the user pays again to repair it.

    🪄

    "Done!" that isn't done

    Reviewers describe the agent saying it built features that don't exist in the app.

    🧾

    No credits back

    Credits spent on failed builds aren't refunded, so users feel they pay for the agent's mistakes.

    Why this matters for Emergent

    The product clearly works for many people: millions of users, and fast working prototypes. The weak spot is trust in the bill. When a user can see that loops are stopped and the agent's own mistakes are free, the same credits feel fair. That protects reviews, refunds and support time.

    How it plugs in

    Watch

    Read the agent's steps: the files changed, the commands run, the test results and the errors.

    Check

    After each step, run the four rules: loop, regression, "done" claims, risky actions.

    Act

    Pause and ask the user, roll back, or tell the agent which claim is false.

    Bill fairly

    Tag each step "progress" or "fixing its own mistake", and charge only for progress.

    Weeks 1–2

    Pull 200 real build logs. Label where loops, regressions and false claims happen. Measure the credits lost.

    Weeks 3–6

    Ship the loop stop and the regression guard behind a flag for 5% of builds. Track credits used and finished apps.

    Weeks 7–12

    Add the "done" check and fair credits. Turn the 12 cases into a release gate that runs before every agent change.
