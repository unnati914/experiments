Evals that remember: 12 chats → 12 saved tests

A made-up support agent for a fictional food-delivery app answers 12 chats in English, Hindi and Hinglish. Every chat becomes a saved test. Each pull request has to pass all of them before it can be merged.

01Every chat becomes a saved test

Click a chat. Failed chats show why they failed, and the test that was saved from them.

02Failures grouped by language

Same agent, same questions. It fails much more often in Hindi and Hinglish.

03A gate on every pull request

Each proposed fix runs all 12 saved tests. green ring = fixed, red ring = broke a test that passed before.

04Test with fake users, before shipping

After both good fixes are merged, the agent talks to made-up users who never wrote in yet.
