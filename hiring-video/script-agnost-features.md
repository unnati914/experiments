**Why Agnost**

Agnost reads every conversation, finds where the agent fails, and opens a pull request to fix it.
I love this idea. So I wrote down five features I would build for you.

**Five features**

One. Prove the fix.
Turn the failed conversations into test cases, and replay them on the old and the new agent, before the pull request is merged.

Two. Don't break what works.
Run every test on every pull request, and block it if something that passed before now fails.

Three. Every language.
Many users write in Hindi, or Hinglish. Group the failures by language, and fix each one.

Four. Find the missing knowledge.
When the answer is not in the agent's documents, the pull request adds it, or fixes the search.

Five. A dashboard for the whole team.
Product managers see the top failures, and turn any conversation into a new test with one click.
